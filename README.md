# 🤖 AI Customer Service Suite

AI‑powered customer support automation for text, email, and voice (Twilio/WhatsApp). The AI answers customer questions based on uploaded company guidelines, works in English, French, and Spanish, and includes a female AI voice introduction. Perfect for small businesses, agencies, and enterprises.

🔗 **Live Demo:** [Your deployed app URL]

---

## ✨ Features

- **Multilingual AI** – English, French, Spanish (UI and responses)
- **Guidelines‑based answers** – Upload PDF, DOCX, or TXT files; the AI replies only from your policies
- **Chat & email simulation** – Test customer interactions instantly
- **Voice integration** – Twilio ready (WhatsApp and voice calls)
- **AI voice introduction** – Female voice explains the software and pricing
- **Global Security Shield** – Visible API key badge (optional)
- **Admin logs** – (coming soon) track every AI decision
- **Payment ready** – Stripe integration for one‑time licenses or subscriptions

---

## 🛠️ Tech Stack

- Python 3.12
- Streamlit
- Groq API (Llama 3.1) / Google Gemini API (optional)
- edge‑tts (Microsoft Edge TTS)
- PyPDF2, python‑docx
- Twilio API (optional)
- Stripe API (optional)
